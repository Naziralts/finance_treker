# 📱 Finance Tracker App

A modern **Finance Tracking Mobile Application** built with Flutter.
This app helps users manage their daily income and expenses, analyze financial data through charts, and securely store transactions locally.

---

## ✨ Features

* 💰 Add, edit, and delete transactions (Income & Expense)
* 📊 Interactive financial charts and analytics
* 📅 Track transactions by date
* 💳 Total balance, income, and expense overview
* 🌙 Dark & Light mode support
* 🔐 Biometric authentication (Fingerprint / Face ID)
* 💾 Offline-first app with local database (SQLite)
* ⚡ Smooth UI with animations
* 🌍 Localization support

## 🛠 Tech Stack

* **Flutter & Dart**
* **State Management:** BLoC (flutter_bloc, bloc_concurrency)
* **Architecture:** Clean Architecture
* **Dependency Injection:** GetIt
* **Database:** Sqflite
* **Charts:** fl_chart
* **Routing:** go_router
* **Local Storage:** SharedPreferences
* **Authentication:** local_auth
* **UI:** Google Fonts, Shimmer, SVG

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Naziralts/finance_treker.git
```

### 2. Go to project folder

```bash
cd finance_treker
```

### 3. Install dependencies

```bash
flutter pub get
```

### 4. Run the app

```bash
flutter run
```
